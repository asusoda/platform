title: Introduction
description: Platform is shared infrastructure for student organizations.
---

Platform is the backend a student organization would otherwise rebuild with every new officer board. One deployment serves many organizations. Each organization is a Discord server. Optional modules switch on or off per organization.

It started as the platform the Software Developers Association (SoDA) at ASU runs its club on. AI Society at ASU extended it with compute, agent memory, search and an MCP server, so the same deployment can back the tools and agents an organization builds.

## What it runs

| Area | Modules |
| --- | --- |
| Operations | Members, points and leaderboards, merch storefront, Notion to Google Calendar sync, job and hackathon alerts, daily LeetCode post, Jeopardy |
| Compute | GPU and CPU pods on the org's RunPod account, SSH certificates, file manager, scheduled sessions |
| Agents | Conversations, memories and profile graph per member, knowledge search, ASU sources, linked Canvas, Google and Outlook accounts |
| Apps | Deploys of the org's own apps to RunPod with health checks and rollback |
| Access | Discord login, officer and member checks, scoped machine tokens, audit log, encrypted org secrets |
